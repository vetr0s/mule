# MULE v0.3.0

## Goal
A project's build becomes a C program, as with nob.h. MULE builds itself that way and the Makefile goes. Four modules carry it: `fs` for files and paths, `args` for command lines, `proc` for running programs, and `build` for staleness, depfiles, the self-rebuild and `compile_commands.json`. Every function that can fail in more than one way takes `Err *` last. Paths and program arguments are `const char *`. Path slicing is on `StrView`. Output goes to `.build/`, so the build binary takes any name, `a.out` by default. The change cuts no release; 0.3.0 is the user's call.

## The caller: MULE's build.c, sketched
```c
#include "base/base.h"
#include "args/args.c"
#include "build/build.c"
/* ...every src/<module>/<module>.c, as the tests include them... */

static const char *const modules[] = { "base", "mem", "str", "err", "arr", "map",
                                       "rand", "time", "log", "fs", "proc", "args",
                                       "build" };

int main(int argc, char **argv) {
    Cmd self = { 0 };
    if (!cmd_append(&self, "-Isrc")) return 1;
    build_rebuild_self(argc, argv, __FILE__, &self); /* returns only when fresh */

    bool no_sanitize = false;
    const char *out = ".build";
    uint64_t jobs = 0;
    const ArgOpt opts[] = {
        { "no-sanitize", 0, ARG_FLAG, &no_sanitize, NULL, "build without ASan and UBSan" },
        { "out", 0, ARG_STR, &out, "DIR", "where output goes (default .build)" },
        { "jobs", 'j', ARG_U64, &jobs, "N", "compile N at once (default: CPU count)" },
    };
    const ArgCmd cmds[] = { { "debug", "debug build of main (default)" },
                            { "test", "build and run tests/test_*.c" }, /* ... */ };
    Args a = { .usage = "build [command] [options] [names...]", .opts = opts,
               .opt_count = 3, .cmds = cmds, .cmd_count = sizeof cmds / sizeof cmds[0] };
    Err err = { 0 };
    if (!args_parse(&a, argc, argv, &err)) { log_error("%s", err.msg); return 2; }

    /* test: compile each stale test in a pool, then run each in order. */
    ProcPool pool = { .max = (size_t)jobs };
    Cmd cc = { 0 };
    bool needed = false;
    if (!build_needs_rebuild_deps(".build/tests/test_str", ".build/tests/test_str.d",
                                  &needed, &err)) ...
    if (needed && !(cmd_append(&cc, getenv("CC") ? getenv("CC") : "cc", "-std=c11", "-Isrc",
                               "-MMD", "-MF", ".build/tests/test_str.d",
                               "-o", ".build/tests/test_str", "tests/test_str.c") &&
                    build_start(&pool, &cc, &err))) ...
    if (!proc_pool_wait(&pool, &err)) ...
}
```

## Acceptance criteria
`fs`
1. `fs_stat` follows links and `fs_lstat` does not. A missing path fails with `ERR_NOT_FOUND`. `mtime_ns` carries nanoseconds on Linux (`st_mtim`) and macOS (`st_mtimensec` under `_POSIX_C_SOURCE`).
2. `fs_read` appends the whole file to `out`. On any failure `out` is unchanged.
3. `fs_write` creates or truncates. `fs_write_atomic` writes a temporary file in the same directory and renames it over the target. A failure leaves the target as it was and removes the temporary. It keeps an existing file's mode, and uses 0644 for a new one.
4. `fs_mkdir_p` succeeds when the directory exists, fails with `ERR_NOT_DIR` or `ERR_EXISTS` when a file is in the way, and names that path in `msg`.
5. `fs_remove` removes a file, a link or an empty directory. `fs_remove_all` removes a tree without following links, and a missing path is success.
6. `fs_copy` copies bytes and mode. `fs_copy_tree` copies a tree, recreating links as links.
7. `fs_walk` visits the root and then everything under it, depth first, each directory's names sorted by byte. `FS_WALK_SKIP` on a directory skips its contents, `FS_WALK_STOP` ends the walk with true. Links are reported as `FS_LINK` and not followed.
8. `fs_exe_path` gives an absolute path that `fs_stat` finds as `FS_FILE`.
9. `fs_basename("a/b.c")` is `b.c`, `fs_dirname` is `a`, `fs_extension` is `.c`. A trailing `/` is ignored. No `/` gives a dirname of `.`. A dotfile such as `.build` has no extension. `fs_join` adds one `/` between parts and joins `check_unchanged_on_oom`.

`args`
10. Each of `--name=value`, `--name value`, `--flag`, `-v`, `-j 8`, `-j8`, and `--` followed by `-x` as a positional parses as written. `-h` and `--help` set `help`.
11. An unknown option, a missing value, a value on a flag, a bad number and an unknown subcommand each fail with `ERR_INVALID`, a message naming the argument, and every output as it was.
12. With `cmds`, the first positional must name one and lands in `cmd`. Positionals land in `rest` in order.
13. `args_help` lists the usage line, the subcommands and every option with its value name and help.

`proc`
14. `cmd_append(&c, "a", "b")` appends two arguments. `cmd_render` writes a line that `/bin/sh` parses back to the same arguments, including empty strings, spaces and quotes.
15. `cmd_run` of `sh -c 'exit 3'` fails with `ERR_EXIT` and code 3. A command that kills itself with signal 9 fails with `ERR_SIGNAL` and code 9. A missing program fails with `ERR_NOT_FOUND` from the parent. A clean exit is true.
16. `CmdIo` redirects stdin, stdout and stderr to files. `cmd_capture` appends the command's stdout to `out`, which is unchanged on failure.
17. A pool with `max` 2 never has more than two running. `max` 0 means the CPU count. A failed job surfaces in the next `proc_pool_start` or in `proc_pool_wait`, which still waits for every job.

`build`
18. `build_needs_rebuild` says rebuild when the output is missing or any input is newer by any number of nanoseconds. A missing input fails with `ERR_NOT_FOUND`.
19. `build_read_deps` reads a `-MMD` depfile with continuation lines and escaped spaces, and lists every prerequisite. `build_needs_rebuild_deps` says rebuild when the depfile is missing.
20. A program built with `MULE_REBUILD_SELF` rebuilds itself after its source or a header it includes changes, runs the new binary with the same arguments, and passes its exit code through. A failed compile puts the old binary back and exits 1.
21. `build_run` and `build_start` log the quoted command before running it.
22. `build_compdb_write` writes valid JSON with `directory`, `file` and `arguments` for every added command.
23. `examples/project/` builds with `cc -I../../dist build.c && ./a.out` in CI.

MULE builds itself
24. `./build` covers every Makefile target, `dist` is byte-identical to the Makefile's, and CI and Release bootstrap with `cc -Isrc -o build build.c`. The Makefile and `tools/amalgamate.sh` are gone.

## Out of scope
- Windows. The `Proc` handle and one-function-per-call-site layout leave room for it in 0.6.0.
- Piping one `Cmd` into another.
- Globbing. `fs_walk` with a filter covers it.
